# Design System

## Surface Colors

| Token | Light | Dark | Usage |
| --- | --- | --- | --- |
| `--background` | #ffffff | #0a0a0a | Page background |
| `--foreground` | #0a0a0a | #fafafa | Default text |
| `--primary` | #1d4ed8 | #3b82f6 | Primary actions |
| `--muted-foreground` | #6b7280 | #9ca3af | Secondary text |
| `--real` | #111111 | #eeeeee | Fixture token |
